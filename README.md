# Para Helga, mi Olga

An interactive, hand-drawn visual letter created for Helga (Olga).

## Features

- Procedural organic gold canvas illustrations.
- Continuous narrative flow with gesture and keyboard support.
- Background acoustic melody via Sufjan Stevens ("Futile Devices").
- Built with React 19, Vite, Tailwind CSS, and Motion.

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```
